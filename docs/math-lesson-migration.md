# 数学互动讲解迁移说明

来源：用户提供的 `edu-agent` 本地项目，迁移范围为 `lesson_engine`、`lib/features/lesson_studio` 和相关测试。未迁入源项目密钥、历史数据、构建目录或 Git 历史。

保留 Flutter / Riverpod / GoRouter 与现有数学功能契约。独立 Node 引擎使用 Fastify、dotenv 和 Zod；这些库保持依赖形式，没有粘贴上游内部源码。Fastify、Zod 为 MIT，dotenv 为 BSD-2-Clause，依赖许可证保留在各包中。源引擎 package.json 声明 ISC，保留该声明；迁移不改变其他文件的权利归属。

数学规则用于读题、求解、原图重建、排课、复核与修复。原有物理回归保留以验证通用引擎，但数学题不会进入物理受力校验或将数学向量当作物理分析箭头移出原图。讲稿目标示例改为数学代数与几何示例。结构检查不等于答案正确性，仍需要独立求解、模型复核和人工抽查。

配置契约：`local.config.json` 管理非敏感启动配置；根目录 `.env.local` 管理服务端 Key。统一启动生成 `build/web/config.json`，只包含本地网关地址、模型和 `proxy-managed` 标记。服务端不接受浏览器提供的真实 Key 或任意上游地址，模型限制为配置中的模型。旧版直接调用模式仍兼容；统一启动后的托管模式清除旧浏览器密钥，恢复文件默认值。

当前交付面向 Windows 本地单用户使用。服务仅绑定回环地址。公网多用户部署需要额外的用户鉴权、限流、任务队列与存储隔离，不在本次迁移范围内。

回滚：对功能提交执行 `git revert`，保留忽略的本地配置和数据以便恢复；切回旧版前关闭当前启动窗口，勿同时让不同版本写同一数据目录。
